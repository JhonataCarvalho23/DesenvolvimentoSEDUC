2 - Por que dividir o trabalho de forma equilibrada é importante para o resultado?

Atividade de registro

Código python

 

from sklearn.model_selection import train_test_split

from sklearn.linear_model import LogisticRegression

from sklearn.metrics import accuracy_score

 

X = [, [4, 0], [1, 3], [3, 1], [5, 0], [2, 2]

]

y = [0, 1, 0, 1, 1, 0]

 

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.33, random_state=42)

 

modelo = LogisticRegression()

modelo.fit(X_train, y_train)

 

previsoes = modelo.predict(X_test)

acuracia = accuracy_score(y_test, previsoes)

 

print(f"Acurácia do modelo: {acuracia * 100:.2f}%")

 

Relatório:

O modelo que eu montei usou Regressão Logística para tentar adivinhar se a galera ia passar ou rodar de ano, olhando só as horas de estudo e as faltas de cada um. No teste deu 100% de acerto, o que parece perfeito, mas a verdade é que isso só aconteceu porque a lista de dados era minúscula, com apenas 6 alunos. Na vida real, esse modelo é bem limitado porque ele não consegue entender situações mais complicadas ou alunos que fogem muito do padrão. Por isso, esse trabalho é só o primeiríssimo passo em Machine Learning. Para fazer um sistema que funcione de verdade em uma escola real, a gente precisaria de uma montanha de dados de verdade, passar horas limpando e organizando tudo, testar vários tipos de algoritmos diferentes e fazer testes muito mais difíceis para ter certeza que o negócio funciona mesmo.
