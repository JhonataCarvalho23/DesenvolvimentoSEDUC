Diferença dos Códigos

O primeiro código é muito simples e foi feito apenas para ser funcional e não bonito, ele possui alguns pontos a ser melhorado como a foto sem um texto alternativo, cores apagadas, html não semântico, um "+" no botão em vez de um texto. Jà o segundo código é uma versão melhorada do primeiro código, corrigindo os pequenos "erros". O segundo código possui um texto alternativo para a imagem, as cores dos textos e etc estão boas e não apagadas, os estilos estão mais bonitos, o código está mais semântico, mudaram o "+" que adicionava um item a lista no código anterior para um texto, adicionou a data do dia que o usuário acessa o site, dois botões de idioma, um para inglês e outro para português, no código 2 também foi adicionado uma label para o campo de tarefa, também foi utilizado no código 2 o aria para o feedback, isso faz aparecer a mensagem "Tarefa adicionada com sucesso!" toda vez que o usuário adicionar uma nova tarefa, o código 2 também permite a navegação pelo site usando a tecla tab utilizando o focus para fazer isso, o código 2 deixou o site mais responsivo utilizando o <meta name="viewport" content="width=device-width, initial-scale=1.0">, o código 2 também não permite adicionar uma tarefa vazia
